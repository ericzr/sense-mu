# 数据集任务类型与类别规范

SenseMu 把“任务类型”和“类别”作为数据集定义的一部分。项目描述业务方向，数据集定义实际的标注契约；同一个项目可以准备多份不同任务类型的数据集。

## 任务类型目录与首发边界

首期产品只允许新建“目标检测”项目和数据集，因为它是当前唯一同时完成内置标注、训练、评测、推理和发布适配的任务类型。其余类型保留为领域契约和路线图，在对应全链路完成前只显示“待接入”，不能创建后再到训练阶段失败。

| 类型 | 标注结构 | 类别 | 当前工作台能力 |
| --- | --- | --- | --- |
| 目标检测 | 轴对齐矩形框 | 必需 | 内置绘制、YOLO 导入、质量检查 |
| 实例分割 | 每个对象一个掩码 | 必需 | 待接入；不可新建 |
| 语义分割 | 每个像素一个类别 | 必需 | 待接入；不可新建 |
| 图像分类 | 整图标签 | 必需 | 待接入；不可新建 |
| 姿态估计 | 关键点与骨架 | 必需 | 待接入；不可新建 |
| 旋转框检测 | 带方向矩形框 | 必需 | 待接入；不可新建 |
| 深度估计 | 像素深度值 | 不使用 | 待接入；不可新建 |
| 文字识别 | 文字区域与转写文本 | 必需 | 待接入；不可新建 |

## 类别维护规则

- 类别编号从 `0` 开始，必须连续；编号会写入标注文件和冻结版本清单。
- 数据集没有标注任务、标注内容或冻结版本时，可以添加、删除和重命名类别。
- 一旦产生上述任一内容，任务类型和类别会锁定。需要改变业务定义时，新建数据集可以保留旧版本的可追溯性。
- 冻结版本保存任务类型和完整类别映射，训练、评测和发布使用冻结快照，不读取后续草稿改动。
- 深度估计不维护类别，提交类别会被拒绝。

## 交互入口

数据与标注页的“类别”标签维护类别；数据集标题旁的任务类型标签打开任务类型设置。新建数据集时先确认任务类型，再导入素材。目标检测可以直接创建内置标注任务；其他类型必须在标注交换、训练引擎、报告、验收和推理协议全部接入后再开放创建。

## 接口

- `POST /api/v1/projects/{project_id}/datasets`：`task_type` 可选，省略时继承项目类型。
- `PATCH /api/v1/datasets/{dataset_id}/definition`：修改草稿数据集任务类型。
- `PATCH /api/v1/datasets/{dataset_id}/classes`：保存连续的类别映射。
- `POST /api/v1/datasets/{dataset_id}/versions:freeze`：把任务类型和类别写入不可变版本清单。

任务类型变更在已有标注任务、标注内容或冻结版本时返回 `409`；类别变更在已有标注或任务时同样返回 `409`。
