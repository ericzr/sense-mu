27. 训练工作区收敛：项目页头的“新建训练”直达页内配置区；主体以训练摘要开始，依次显示新建训练、运行记录、模型版本和独立数据检查。未新增任何虚构的 GPU、费用或训练指标。
28. 标注任务真实任务层：新增持久化标注任务与任务素材快照，任务创建、列表、状态更新和进度统计均由 API 根据真实素材与 YOLO 标注计算；尚未把通用画框编辑器和智能预标注模型接入任务执行。
29. 标注编辑器真实读写：编辑器读取任务快照中的真实图片和 YOLO 标注，支持按图片实际显示区域拖拽绘制矩形框、撤销/重做（含 `Ctrl/Cmd + Z` 快捷键）和删除恢复；保存时通过现有对象存储校验链回写标注文件，提交检查会更新任务状态。多边形、智能预标注和视频抽帧仍明确保持未开放或预览状态。
30. 视频文件真实抽帧：MP4、MOV、WebM 先登记为不可训练的来源文件，再由持久化抽帧任务和独立 Worker 队列生成图片；API 校验任务产物、按内容去重并写回当前数据集。视频流在安全访问合同明确前保持不可用。
31. 视频抽帧任务恢复：抽帧 Worker 使用真实租约心跳；维护任务会回收失联尝试、重新分发可重试任务并拒绝旧尝试回写；数据页提供处理中任务的取消操作，取消后不会登记新的训练素材。
32. 抽帧到标注的精确衔接：每次抽帧按帧序号记录实际输出素材；完成后可从任务行幂等创建仅包含该批素材的手动标注任务，不按时间推断“最近一批”，也不混入其他未标注图片。
33. 标注任务包交换：任务固定类别表并提供带 `sensemu-task.json` 清单的 ZIP 导出/导入；服务端按任务 ID、数据集 ID、素材集合、图片 SHA-256、字节数、类别和坐标全量校验，合法导入后按真实标注回写进度。1.1 任务包始终包含 YOLO，图片尺寸完整时还包含标准 COCO；导入会拒绝同一包同时修改两种标注来源。
34. 类别定义持久化：数据集保存 `class_map` 作为唯一类别来源；标注任务、视频抽帧标注任务和冻结版本继承已保存类别，已有标注或任务后拒绝修改，未保存类别时阻止继续创建。
35. 对象导航操作闭环：工作台的“数据与标注 / 训练 / 发布”分组在标题悬浮或键盘聚焦时提供新增入口；资源行只在悬浮、当前或聚焦时显示删除、归档、停用动作。所有不可逆操作先经确认弹窗，再由 API 校验运行任务、冻结版本、标注任务、视频抽帧任务和在线服务等保护条件；操作完成后刷新资源树并在当前对象被移除时返回概览。
36. 标注画框交互收口：矩形框工具改为按住拖拽并提供虚线预览，坐标以 `object-fit: contain` 后的实际图片区域换算，避免留白区域造成偏移；指针释放位置不论落在画布或已有标注上都会完成或清理草稿。
37. 数据版本冻结门禁：存在“标注中”或“待检查”的标注任务时，前端会显示具体任务并禁用冻结入口，后端也会拒绝冻结；所有任务进入“已完成”且数据校验通过后，才允许生成不可变版本。
38. 标注审核闭环：待检查任务在编辑器中提供“完成检查”动作，先保存当前素材再请求服务端更新为“已完成”；保存或完整性校验失败时不会误更新任务状态，已完成任务显示为“已完成”状态入口。
39. 数据到训练的版本深链：从数据集版本页进入训练时携带当前冻结版本 ID，训练配置默认选中同一版本，避免跨版本误训练；训练服务端仍只接受已冻结且同时包含训练集与验证集的版本。
40. 项目概览导航收敛：移除重复的“数据 / 训练 / 发布”横向状态按钮，概览仅保留项目状态、当前下一步和最近产物，具体状态由侧栏和对应页面承载。
41. 模型检查结果可解释：模型详情复用真实评测记录，展示验收数据、核心指标、逐条门禁的目标值/实际值/原因与最终结论；没有评测记录时不生成占位结果。
42. 训练事件时间线与移动端层级：训练任务详情读取真实运行事件并按顺序展示状态、进度和失败原因；项目头部在移动端改为自适应高度，确保“新建训练”不被下一步卡片或详情内容遮挡。
43. 真实训练报告链路：Worker 上传的 `results.csv` 通过工作区权限接口读取，训练任务与模型详情仅在真实产物存在时展示核心指标曲线；接口限制 1 MB / 2000 行、过滤非有限数值，对象缺失返回未可用而不暴露存储地址。
44. 本地演示种子：`make seed-demo` 仅在 development + SQLite + 本地对象存储下写入一个明确标记的 PPE 演示项目，包含合成图像、YOLO 标注、冻结版本、完成训练事件、模型版本和 `results.csv`；仅供验证界面，不代表真实训练或验收。
45. 真实训练可视化：Worker 仅在 Ultralytics 实际产出时上传混淆矩阵 PNG；训练详情通过工作区权限接口读取并以 Blob 显示，固定白名单、PNG 校验和大小上限避免暴露对象存储地址或混入非训练文件。
46. 真实类别指标与模型对比：训练成功后，Worker 使用最终模型对同一冻结验证集进行隔离复核；仅将实际输出的每类 precision / recall / mAP 写为不可变 JSON。训练和模型详情按工作区权限展示类别表，训练页可在两个已登记模型版本间直接比较聚合指标；本地演示只补第二个明确标记的 Mock 版本以验证对比交互，不伪造类别级评测。

## 当前信息架构

- 一级导航只保留 `工作台 / 算法市场 / 数据市场 / 我的` 四个页面。
- `工作台` 面向算法生产；展开侧栏按真实对象列出数据与标注、训练和发布，首页仅保留资源统计、数据集、训练项目和最近活动。侧栏选择对象，对象页签只切换当前对象的内部内容，不再重复展示项目生命周期导航。
- `算法市场 / 数据市场` 都是面向消费者的商城，只承担搜索、筛选、预览、详情和购买，不再混入发布管理、我的订单和用量。
- `我的` 在同一页切换生产端和消费端：生产端承接原供应方中心、商品、销售订单、收入、算力与收款设置，其中“算力与托管”只汇总项目中的训练任务和在线服务；消费端承接已购 API、已购数据、购买订单、消费用量和钱包。
- 设置作为“我的”的二级内容；发布与推理属于项目内容；平台运维能力不进入普通用户主导航。
- 四个一级页面必须共用同一页头基线，移除“工作区项目”、“调用授权市场”等重复标识和非必要解释文字。完整决策见 `docs/adr/0029-four-surface-user-information-architecture.md`。
