# SenseMu 用户页面收敛基线

- 更新日期：2026-08-13
- 状态：当前产品基线
- 适用范围：普通生产方、算法与数据购买方

## 1. 产品心智

SenseMu 只向普通用户呈现四个一级页面：

| 一级页面 | 面向谁 | 只解决什么问题 |
|---|---|---|
| 工作台 | 算法生产方 | 查看项目和数据，进入项目继续生产 |
| 算法市场 | 算法购买方 | 找到、了解并购买可调用算法 |
| 数据市场 | 数据购买方 | 找到、了解并购买可训练数据 |
| 我的 | 所有用户 | 管理商品、订单、API、算力、费用和设置 |

平台运维、审核、Worker、推理网关、服务器节点和支付渠道不是普通用户心智，不进入一级导航。

## 2. 工作台生产导航与项目闭环

工作台仍是唯一生产端一级页面，但展开后直接呈现三个可折叠对象集合：

- `数据与标注`：数据集、素材、标注任务、类别统计和数据版本；
- `训练`：项目、训练任务和模型版本；
- `发布`：在线服务和调用状态。

侧栏收起时保留这三个集合的快捷图标，只隐藏名称和对象列表；移动端菜单始终展示完整结构。数据页不再重复显示工作区、项目和数据集侧栏。

工作台首页固定为四个区块：资源统计、数据集、训练项目和最近活动。侧栏负责选择数据集、项目或在线服务；进入对象后，页签只切换该对象的内部内容。不再同时保留“数据 / 训练 / 发布”侧栏与“概览 / 数据 / 训练 / 发布与调用”页签。

数据集页使用 `素材 / 标注 / 类别与统计 / 模型 / 版本` 五个内部视图。素材视图支持真实图片预览、数据划分筛选、搜索、网格/列表切换、图片/视频导入和视频流抽帧。

项目页面负责创建和迭代；“我的”只做跨项目汇总与费用管理，不复制项目内的复杂配置表单。

## 3. 生产与消费

“我的”顶部只保留两个容易理解的视图：

- `创作与销售`：我的商品、销售订单、算力与托管、收入和收款设置。
- `购买与使用`：已购 API、已购数据、购买订单、消费用量和钱包。

训练算力与算法托管不是新的商城，也不是新的一级页面：

- 在项目“训练”中创建训练任务；
- 在项目“发布与调用”中创建在线服务；
- “发布与调用”内部固定为 `实时分析 / 批量处理 / 服务设置 / 事件`；当前只开放已验证的“视觉小模型 + 图像”，多模态大模型和实时视频流在服务端合同完成前显示待接入；
- 在“我的 > 创作与销售 > 算力与托管”中查看所有项目的训练任务和在线服务。

## 4. 页面与文案规则

- 四个一级页面共用相同内容宽度、左边距、顶部间距和标题基线。
- 页头只保留一个主标题和必要操作，不增加口号、英文眉题和解释性副标题。
- 一项动作只有一个主要入口；汇总页可以跳转到详情，但不复制创建表单。
- 优先使用“项目、数据、训练、模型、在线服务、API、订单、费用”等日常词语。
- `YOLO`、`mAP50`、`API` 等无法准确替换的专业名词可以保留。
- 没有真实合同或后端事实时显示“尚未开通”，不展示虚构价格、余额、GPU 型号或服务等级。
- 市场卡片只显示判断类型和质量所需的核心信息；详细来源、限制和规格进入独立详情页。
- 图片使用裁切填充保持比例，不拉伸，不在卡片内展开详情。

## 5. 不应重新引入的页面

- 独立“供应方中心”；
- 独立“在线服务”一级入口；
- 独立“服务器托管”一级入口；
- 独立“设置”一级入口；
- 同时混合商品发现、发布审核、订单、账单和服务运维的综合页面。

这些能力分别归入项目二级页面或“我的”。旧路由只承担兼容跳转。

## 6. 当前主线

页面骨架已经收敛，后续优先补真实业务事实，不再横向增加页面：

1. 为训练任务补资源占用、开始/结束时间和可审计用量；
2. 为在线服务补托管方式、运行健康度和可审计用量；
3. 在合同确定后分别接入训练费用、托管费用和销售收入明细；
4. 使用首批客户的真实训练报告、服务指标和商品内容替换剩余演示数据；
5. 完成生产数据库、对象存储、备份恢复和运行告警。

涉及四页面边界的正式决策见 `docs/adr/0029-four-surface-user-information-architecture.md`；训练与托管归属见 `docs/adr/0030-managed-training-and-inference-hosting.md`；对象式生产导航见 `docs/adr/0031-object-oriented-workbench-navigation.md`。
