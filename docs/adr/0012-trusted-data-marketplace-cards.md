# ADR-0012：可信数据卡先于数据交易

- 状态：Accepted
- 日期：2026-08-09

## 决策

数据市场第一阶段只开放可信数据卡的发现与供应方发布，不提前开放购买、下载或计算到数据。公开对象绑定一个不可变的 `DatasetVersion`，并必须声明来源、采集方式、场景覆盖、已知限制、隐私处理、许可证和机器可执行的用途权限。

只有工作区管理员或所有者可以发布；数据版本必须已冻结且非空，供应方必须确认拥有公开与授权权利。首阶段直接拒绝含个人数据的资产，不以一份自我声明替代专项隐私审核。公开响应不包含 manifest 地址、对象地址或样本下载链接。

## 原因

数据交付仍需在“可下载冻结版本”和“计算到数据”之间作出产品决策，两者的授权检查、存储隔离、撤销、删除证明和成本结构不同。在该决策前生成付费订单或通用下载链接会制造无法真实履行的权益，因此先完成可信发现层。

## 信任标识

当前数据卡明确标记为“供应方声明”，不伪装成平台审核。未来引入平台抽样复核、安全扫描或第三方权利证明时，应增加独立审核记录和状态迁移，不覆盖原始声明。

## 后续条件

开放数据交易前必须明确：交付模式、许可证合同、支付与退款时序、对象访问方式、授权撤销、地域限制、数据保留与可验证删除策略。
