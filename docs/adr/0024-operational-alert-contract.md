# ADR-0024：控制面运行告警契约

- 状态：Accepted
- 日期：2026-08-11

## 决策

API 新增 `GET /health/operational`，提供可由任意部署平台轮询的聚合运行态摘要。它不绑定 Prometheus、云监控或告警通知供应商，也不返回工作区、任务、请求或 Webhook 地址。

当前指标只覆盖可由控制面事实数据库验证的异常：等待超时的训练任务、超出执行租约未续期的任务、失败或超过投递阈值的 Webhook，以及超时未结算的用量预留。任一指标非零时，整体状态为 `attention`；数据库查询不可用时返回 `503` 和 `unavailable`。

## 原因

存活与就绪探针只能判断进程和依赖可访问，不能说明业务队列、Worker 租约和异步投递是否积压。先定义稳定、低敏感度的告警语义，能够在首发部署平台选定后直接映射为阈值告警，而不把运行监控实现绑定到某个厂商。

## 边界

推理网关和运行时仍由各自的 `/health/ready` 提供就绪、缓存和容量事实；基础设施 CPU、内存、GPU、网络和容器重启次数由部署平台采集。本接口不取代日志、链路追踪或备份恢复演练。
