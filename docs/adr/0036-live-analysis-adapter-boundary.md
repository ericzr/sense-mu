# ADR-0036：实时分析的模型与视频流边界

## 背景

项目“发布与调用”已能将通过独立检查的视觉小模型发布为在线服务，并对单张图像进行真实推理和成功调用计量。多模态大模型与实时视频流尚无供应商凭据、隐私、成本、网络访问、采样和任务恢复合同。如果只增加前端选项，会让用户误以为这两条链路已经可用。

## 决策

- 实时分析固定属于项目内的 `/services?view=live`，不新增一级页面。
- 页面将“算法”和“输入”分开选择：算法为“视觉小模型 / 多模态大模型”，输入为“图像 / 实时视频流”。
- 首期只开放已经端到端验证的“视觉小模型 + 图像”。其他组合显示真实的待接入状态，不返回 Mock 结果。
- 多模态模型通过服务端适配器调用。适配器固定供应商、模型标识、请求协议版本、超时、重试、数据保留和计量规则；浏览器不持有供应商凭据。
- 实时视频流必须使用加密凭据引用，不在数据库、日志、任务规格或前端中明文保存 RTSP 等地址。
- 视频流任务固定窗口、采样频率、所用模型版本、输出合同和事件去重规则，复用租约、心跳、取消、失联恢复和幂等事件投递。
- 图像实时调用、视频流任务、冻结数据批量推理和市场计费保持独立任务与授权边界。

## 实现顺序

1. 用页内视图收敛“实时分析 / 批量处理 / 服务设置 / 事件”，并保留已验证的小模型图像调用。
2. 建立多模态供应商适配器、服务端凭据引用和图像请求审计，选定首个供应商后再开放界面。
3. 建立视频流源、网络出口白名单、采样 Worker 和恢复任务，完成断流、重连和旧执行尝试回写拒绝测试后再开放界面。

## 结果

用户可以在同一页看懂当前可用能力和待接入能力；产品不会因为前端有选项就越过凭据、隐私、运行时和计量边界。
