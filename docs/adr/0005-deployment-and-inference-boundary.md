# ADR-0005：发布控制面、推理网关与幂等计量

- 状态：Accepted
- 日期：2026-08-09

## 决策

模型发布由核心 API 控制，推理流量由独立网关承载。创建 `Deployment` 时必须找到该模型在项目当前生效门禁策略下的 `approved` 评测；训练成功、模型曾经通过旧策略或仅修改模型状态都不足以发布。

每次发布写入不可变 `deployment-spec.json`，固化模型产物、任务类型、推理协议、门禁报告与策略版本。运行中的服务不会因为项目后来创建新门禁策略而被静默停用；但被停用的服务只有在模型通过当前策略后才能重新启用。

公共推理地址包含工作区标识和端点标识：`/inference/v1/workspaces/{workspace_slug}/endpoints/{endpoint_slug}:predict`。端点标识只需在工作区内唯一，避免不同租户之间发生路由歧义。

## 密钥与网关

服务 API 密钥由核心 API 生成，只在创建或轮换时返回一次。数据库只保存可识别前缀和 SHA-256 摘要，不保存明文；不可变发布规格也不得包含密钥。推理网关使用独立内部凭据向核心 API 解析端点，核心 API 同时校验服务状态和用户 API 密钥。

网关不直接读取业务数据库或对象存储。它拿到经过授权的模型运行信息后调用配置好的推理运行时，并保持稳定的外部请求与响应协议。没有运行时时明确返回不可用，不生成模拟预测。

## 调用计量

只有运行时成功返回后，网关才向核心 API 登记 `UsageRecord`。每个调用携带 `X-Request-ID`；数据库以请求编号唯一约束保证重复提交不会重复计量。同一请求编号若携带不同的服务、能力或计量单位则拒绝处理。

当前计量单位是成功处理的图像数，能力标识为 `vision.predict`。货币定价、账户余额和市场分成属于后续商业结算层，不在本次发布合同中提前实现。

## 当前边界

网关具备端点解析、密钥校验、运行时转发和成功调用计量合同。受限的 Ultralytics 实现及其输入、缓存和隔离边界由 ADR-0006 定义；当运行时进程未启动时，网关仍会真实返回不可用，不产生模拟预测或计量记录。
