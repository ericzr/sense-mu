# ADR-0018：首期工作流只提供受限模板

- 状态：Accepted
- 日期：2026-08-10

## 决策

首期 `WorkflowSpec` 只支持 `ppe-violation-webhook.v1`：调用一个已发布的 `CapabilitySpec`，按固定去重窗口筛选声明过的 PPE 业务事件，再输出到一个公开 HTTPS Webhook。工作流引用能力版本的内容哈希，配置和版本发布后不可原地修改。

创建时服务端校验工作区、项目归属、能力版本状态和事件类型；Webhook 地址禁止凭据、非 HTTPS、非默认端口以及明确的本地或私有 IP。当前只固化模板契约，实际 `VisionEvent` 生成、签名、重试和投递结果将在下一阶段实现。

## 原因

固定模板足以验证首个 PPE 垂直的“检测 → 事件 → 业务系统”路径，同时保持运行时、计量和权限边界清晰。自由拖拽画布会提前引入任意图结构、循环、动态分支、凭据管理和成本模拟，不符合当前产品的克制边界。

## 当前非目标

本次不支持任意 Block、循环、动态 URL、Kafka/MQTT、人工审核节点、多能力组合或公开工作流市场。新增模板必须先有可重复的客户流程和独立的运行时契约。
