# ADR-0003：数据版本就绪条件

- 状态：Accepted
- 日期：2026-08-09

## 决策

数据集本身是可变草稿，`DatasetVersion` 是训练输入的不可变快照。目标检测数据只有同时满足以下条件才能冻结：

- 定义了从 0 开始且连续的类别编号；
- 每个资产已明确划分为训练集、验证集或测试集；
- 训练集和独立验证集均至少包含一个资产；
- 每个资产都关联了可读取的 YOLO UTF-8 标注；
- 每行标注包含类别编号和四个归一化框坐标，且类别编号存在于当前类别定义中。

图片和标注都通过对象存储直传，API 在登记时校验文件大小、SHA-256 和 YOLO 基础格式，在冻结时结合类别定义再次做完整校验。冻结 manifest 保存资产地址、标注地址、数据划分和类别定义，Worker 只消费 manifest，不读取可变草稿。

## 产品边界

首版只提供标准 YOLO 文本标注导入，不自研画框标注器。需要可视化标注时，优先接入成熟标注工具或导入其导出结果。这样可以先确保训练数据合同、可追溯性和执行闭环成立，避免把资源投入非核心编辑器功能。

## 后果

旧的、不满足就绪条件的已冻结版本继续保持不可变，训练 Worker 会在预检阶段给出真实失败原因。后续新版本必须先在数据工作台修复草稿，再重新冻结；不得原地修改历史 manifest。
