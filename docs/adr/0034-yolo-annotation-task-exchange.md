# ADR-0034：标注任务使用带清单的 YOLO / COCO 交换包

- 状态：已采纳
- 日期：2026-08-14

## 背景

标注任务已经能够固定素材快照，并通过对象存储逐张登记 YOLO 文本。继续在 SenseMu 内扩展通用画框编辑器会扩大前端和标注领域的边界；成熟标注工具更适合承担人工协作。因此任务需要一个可复现、可校验的交接格式。

## 决策

- 标注任务详情提供导出和导入两个动作，均使用同一个任务 ID，不新建独立的标注工作台。
- 导出包为 ZIP，包含 `sensemu-task.json`、`data.yaml`、原始图片、同名 YOLO `.txt` 文件和简短说明。图片尺寸完整时，同一包还包含标准 COCO `annotations/instances.json`，可直接交给支持 COCO 检测格式的成熟工具。清单记录任务、数据集、类别表、素材 ID、图片路径、媒体类型、字节数和 SHA-256。
- 1.1 清单同时记录导出时的 YOLO 标签和 COCO 文件哈希。导入会识别被外部工具修改的唯一标注来源；同时修改两种格式会拒绝整个任务包，避免不透明的覆盖顺序。
- 导入只接受当前任务上传路径下的 ZIP，并要求清单版本、任务 ID、数据集 ID、类别表和完整素材集合完全匹配。COCO 图片 ID、文件名、尺寸、类别 ID 与名称必须保持不变；检测框必须在登记图片范围内。
- 导入逐张校验原始图片字节数和 SHA-256，校验标签文件的 UTF-8、五字段格式、归一化坐标和类别编号；任何一张失败都会拒绝整个任务包，不产生部分写回。
- 通过校验的标签写入任务专属对象路径，任务进度继续由 `DatasetItem.annotation_uri` 真实计算。导入不会自动跳过检查或把任务直接标记为完成。
- 外层 ZIP 也必须经过对象存储的字节数和 SHA-256 校验；当前同步导出限制任务素材总登记大小不超过 512 MB。缺少图片尺寸元数据的历史任务仍可使用 YOLO，不宣称具备 COCO 兼容性。

## 非目标

- 不实现通用标注器、协同锁、逐点编辑或实时标注回调。
- 不允许导入只凭文件名匹配的散装图片和标签；外部工具必须保留 SenseMu 清单及原始图片。
- 不把任务包导出与公开数据交付、数据市场下载或批量推理产物混用。

## 后续

1. 用首个外部标注工具验证 ZIP 清单保留和结果导入流程。
2. 当任务规模超过同步边界时，把导出改为 Worker 生成对象存储产物，API 只发放短期下载地址。
3. 在明确模型供应商、成本、隐私和审核合同后，再增加带模型版本和人工接受记录的多模态预标注结果导入。
