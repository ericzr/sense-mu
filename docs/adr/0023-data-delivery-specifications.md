# ADR-0023：数据卡必须先固化交付规范

- 状态：Accepted
- 日期：2026-08-11

## 决策

每张新公开数据卡同时创建一份不可变的 `DataDeliverySpec`。它绑定一个冻结数据版本、许可证及用途权限的快照，以稳定 JSON 写入私有对象存储，并记录内容哈希。公开目录和受保护的规范接口只返回可审计元数据、交付方式、访问边界和激活条件，绝不返回对象地址、内部 manifest 或样本链接。

当前唯一规划的交付方式是 `workspace_copy_after_authorization`：在有效的数据访问授权、许可条款确认和买方工作区确认之后，将副本导入买方工作区。原始对象存储不向买方生成直链。规范状态为 `prepared_not_open`，因此它不是购买、下载或授权接口。

## 原因

数据卡只证明来源和适用性，不能证明平台能够按许可证履约。将数据版本、许可和交付边界固化为可验证快照，使后续支付、授权、撤销和交付记录都能引用同一事实，而不是依赖可变的页面文案或供应方原始数据。

## 未决边界

正式交付仍需先确定首发地区、经营主体、支付渠道、许可证合同、买方副本删除证明和保留期限。撤销在当前规范中只表示阻断后续平台访问；已经交付的买方副本如何留存、删除或审计，必须由最终合同和首发地区规则确定后再实现。
