# ADR-0016：首阶段算法市场采用平台精选审核

- 状态：Accepted
- 日期：2026-08-10

## 决策

首阶段算法市场不开放自由发布。供应方只能把满足生产发布与独立验收门禁的目标检测服务提交给平台；提交创建或更新为 `pending_review` 状态的商品，但不会公开、不会出现在买方目录中，也不能创建调用授权订单。

平台内部审核服务使用独立的审核凭据调用内部接口，作出 `approved` 或 `rejected` 决定。只有批准会将商品切换为 `published` 并记录公开时间。供应方工作区不能购买自己的算法商品。

## 审核事实与重新提交

每次审核都追加一条独立的审核事实，保存审核人、结果、说明与审核时间。审核记录不覆盖也不物理删除。

商品被拒绝后，供应方可修改商品元数据并从原生产服务再次提交。商品回到 `pending_review`，历史拒绝和后续批准均保留在审核记录中；公开目录只读取当前为 `published` 的商品。

## 原因

算法商品直接承载客户调用流量与商业授权。首批客户前，平台需要验证模型适用边界、独立验收依据、服务可用性与商品描述一致性。精选审核以很小的控制面换取清晰责任边界，避免在验证阶段过早建设开放卖家市场、自动风控或申诉系统。

## 当前非目标

本次不建设公开卖家注册、自助审核后台、多级审核、申诉流、评分排名、自动内容审核或佣金结算。审核接口只供平台内部服务调用，不能作为供应方或公开客户端 API。
