# ADR-0031：工作台采用对象式生产导航

- 状态：Accepted
- 日期：2026-08-13

## 背景

四页面架构解决了生产、消费和账户管理混在一起的问题，但工作台内部仍以“项目详情四步骤”为主要入口。随着数据标注、训练模型和在线服务逐步落地，用户需要先进入项目，再寻找对应步骤；同时数据页又保留第二条工作区/项目/数据集侧栏，形成重复导航。

Ultralytics Platform 的有效结构不是增加更多全站一级页面，而是在生产入口中直接列出三类核心对象：数据集、训练项目和在线部署。用户从对象集合进入对象详情，详情页再承接该对象的视图与操作。

## 决策

SenseMu 继续保留四个全站一级页面：`工作台 / 算法市场 / 数据市场 / 我的`。

`工作台`在展开侧栏时显示三个可独立折叠的生产对象集合：

1. `数据与标注`：列出真实数据集和素材数量，进入数据集对象页；
2. `训练`：列出真实项目和模型数量，进入项目/模型生命周期；
3. `发布`：列出真实在线服务，进入发布与调用页。

这些分组是工作台的二级导航，不是新的全站一级页面。算法市场、数据市场和我的仍保持原有边界。

侧栏不再使用“工作”小标题叠加“工作台”入口。“工作台”本身就是返回生产概览的主入口，三个对象集合紧随其下。

## 导航职责

- 主侧栏选择工作对象：数据集、训练项目或在线服务；
- 对象页的页签只切换当前对象的内容；
- 删除项目页内重复的“概览 / 数据 / 训练 / 发布与调用”生命周期页签；
- 数据集页保留“素材 / 标注 / 类别与统计 / 模型 / 版本”，因为它们是数据集对象的内部视图。

## 收起状态

侧栏收起时不切换成另一套信息架构：

- 保留工作台、算法市场、数据市场和我的四个一级图标；
- 在工作台图标下保留数据与标注、训练、发布三个纵向快捷图标；
- 隐藏对象名称与对象列表；
- 快捷图标进入该集合的默认对象，无对象时进入对应空状态页；
- 移动端抽屉始终使用完整展开结构。

因此收起只压缩信息密度，不改变入口顺序和用户心智。

## 对象详情结构

### 数据集

数据集页直接呈现对象标题、状态、描述和真实统计，并使用以下视图：

- `素材`：图片、视频和视频流抽帧；
- `标注`：人工标注、智能预标注和检查任务；
- `类别与统计`：类别分布、素材数量、标注实例和覆盖率；
- `模型`：使用该项目数据训练得到的模型版本；
- `版本`：不可变数据版本和质量报告。

原数据页的工作区/项目/数据集二级侧栏删除，选择对象统一由主侧栏承担。

“素材”视图进一步按数据集处理心智组织：顶部显示任务类型、就绪状态、素材数、已标注数、标注实例、体积和更新时间；工具层提供训练/验证/测试/未划分筛选、搜索和网格/列表切换。网格只显示真实上传素材的预览，不生成模拟图片。

### 训练与模型

训练页不视为“项目流程的第三步”，而是训练对象的工作区。页头负责项目身份和“新建训练”单一主动作；内容区按“训练摘要 → 新建训练 / 运行记录 → 模型版本 → 独立数据检查”排列。训练摘要仅显示真实的数据版本、训练任务、模型版本与运行中数量。
模型详情逐步收敛为：

- 概览；
- 训练过程；
- 在线测试；
- 导出；
- 发布。

当前后端尚未提供真实曲线文件和导出任务合同的部分，只保留现有真实参数、指标和发布状态，不生成模拟曲线或虚假导出记录。

### 发布

发布集合只列真实部署；发布页继续承接模型检查、在线服务、API 测试、批量推理、能力契约和事件投递。未发布时显示真实空状态。

## 工作台首页

工作台首页收敛为四层真实信息：资源统计、数据集、训练项目和最近活动。它提供且只提供两个新建动作：新建数据集与新建项目。不展示虚构的 GPU、费用、存储额度或训练曲线。

## 与 ADR-0029 的关系

本决策修订 ADR-0029 中“项目内四个步骤不进入主导航”的表述：四个全站一级页面不变，生产对象集合可以在工作台项下作为二级导航展开；项目内不再保留重复的生命周期导航。

## 非目标

- 不复制 Ultralytics 的品牌、AI 助手、地区列表或未落地商业能力；
- 不因为竞品存在就创建没有真实后端事实的页面；
- 不把 Annotate、Train、Deploy 提升为与算法市场、数据市场、我的并列的全站一级入口；
- 不同时保留主侧栏对象列表和页面内重复对象侧栏。
