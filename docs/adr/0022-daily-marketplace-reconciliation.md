# ADR-0022：商业事实使用只读日级对账

- 状态：Accepted
- 日期：2026-08-10

## 决策

平台以 UTC 日为边界，从不可变订单、已验证支付事件、额度预留、成功用量记录和供应方收入账本生成只读对账报告。报告只允许持有平台审核内部凭据的服务读取；不暴露买方密钥、支付编号、Webhook 地址或原始业务输入。

报告显式汇总订单授权额、收款/退款事件、全部成功用量、市场用量、收入账本和超时预留，并检查三类异常：市场用量缺少账本、账本金额与单价/用量不一致、超时预留未被恢复。已收款但属于已被后续订单替代的订单也单列为人工处理项。

## 原因

订单、支付和用量处在不同生命周期。只展示其中任一视图会掩盖计费正确但收入漏记、支付收到但未授权、或 Worker 故障后遗留预留等问题。首期采用可重复计算的只读报告，避免提前建设总账、数据仓库或自动打款流程。

## 边界

- 报告不写入结算状态，不自动修复异常，也不触发支付或退款。
- 供应方结算、税务发票和支付渠道拉单仍由后续的正式适配器承担。
- 日级报告是运营核对依据；金额与会计确认、税务确认不是同一概念。
