# ADR-0013：供应商中心只聚合可验证事实

- 状态：Accepted
- 日期：2026-08-09

## 决策

供应商中心以工作区为供应主体，聚合已有算法商品、数据卡、客户授权、成功计量、销售订单、支付与退款事实以及待结算收入。供应方档案只保存公开名称、说明、支持邮箱、网站、服务区域和支持承诺。

主体认证、收款配置、平台审核和提现结算均使用独立状态，不因档案填写完成、商品上架或产生用量而自动变为通过。当前没有对应外部服务或运营流程，因此这些状态保持“未开始、未提交或未开放”。

## 财务口径

- 销售授权上限来自供应方订单的授权金额快照，不等于已收款。
- 实收与退款金额只来自经过支付适配器验证的归一化事件。
- 待结算收入只由成功推理用量计提，不等于可提现余额。
- 额度耗尽或已过期的调用授权不计入有效客户授权。

供应方订单按“供应工作区 + 创建时间”查询，并建立与该访问模式一致的数据库索引。

## 权限边界

只有工作区管理员和所有者可以读取供应方账本或修改公开档案。普通成员和查看者不能通过隐藏前端入口绕过服务端授权。

## 非目标

本次不建设实名/企业认证、银行账户绑定、税务发票、结算批次、提现、平台审核后台或争议处理。后续接入这些能力时必须写入独立事实记录，不能直接编辑聚合金额。
