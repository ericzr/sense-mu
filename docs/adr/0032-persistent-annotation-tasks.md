# ADR-0032：标注任务先固化素材快照，再接入专业标注工具

- 状态：已采纳
- 日期：2026-08-13

## 背景

数据页已有图片导入、YOLO 标注文件登记和不可变版本冻结，但“标注任务”此前只是前端示例数据。任务创建不会写入服务端，也无法在刷新或换设备后恢复，进度数字因此不具备业务意义。

## 决策

- 在 API 中持久化 `AnnotationTask` 和 `AnnotationTaskItem`。
- 创建任务时按数据集当前状态选择“未标注素材”或“全部素材”，把素材 ID 固定为任务快照；后续数据集新增素材不会悄悄进入已有任务。
- 任务进度由任务素材中实际存在的 `DatasetItem.annotation_uri` 计算，不能由前端递增或估算。
- 首期只允许“手动标注”任务；智能预标注接口在模型供应商、成本、隐私和审核合同确定前返回明确的未开通错误。
- 任务状态只允许进入“待检查”或“已完成”；标记完成前服务端必须确认任务内所有素材已有可校验的 YOLO 标注。
- 任务详情返回素材列表，编辑器后续通过该列表使用外部专业标注工具或受控导入/导出协议。

## 非目标

- 不在 SenseMu 内自研通用矩形框、多边形、画笔编辑器。
- 不把视频抽帧的前端提示视为实际任务；抽帧必须由 Worker 生成真实素材后再进入标注任务。
- 不用静态示例框或模拟进度替代模型输出和人工审核事实。

## 后续

1. 为视频文件和视频流增加持久化抽帧任务及 Worker 产物登记。
2. 选择一个具备任务回调、导入导出和权限隔离的标注工具，接入任务跳转与结果回写。
3. 接入多模态预标注时，保存模型版本、输入快照、建议结果和人工接受记录。
