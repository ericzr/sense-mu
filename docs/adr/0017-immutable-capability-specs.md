# ADR-0017：能力以不可变 CapabilitySpec 交付

- 状态：Accepted
- 日期：2026-08-10

## 决策

可交付、可审核的能力不等同于模型文件或在线服务。SenseMu 将通过独立验收门禁的生产服务固化为版本化 `CapabilitySpec`，其至少包含问题定义、输入限制、稳定输出协议、类别与业务事件、适用边界、交付方式，以及模型版本、服务端点和验收依据。

每份 CapabilitySpec 写入业务库，同时以规范化 JSON 存入对象存储；内容哈希覆盖整份文档。创建后不提供原地修改接口。一个能力标识在同一工作区可有递增版本，但同一个服务端点只能固化一次契约；更新必须基于新服务版本重新固化。

## 准入边界

只有已发布的生产服务可以固化能力契约。输出协议必须与项目任务类型一致，能力文档中的模型版本和独立验收依据由服务端解析，而不信任客户端提交的引用。

本次先保持市场商品与 CapabilitySpec 解耦，避免对已验证的订单、授权、支付和退款链路进行同步重构。下一阶段市场商品将显式引用已批准的 CapabilitySpec 版本，替换当前直接引用服务端点的过渡模型。

## 当前非目标

本次不建设通用能力编辑器、运行时可变参数、拖拽式工作流或多模型编排。输入媒体类型、单次负载上限和交付方式采用第一阶段的有限枚举，新增能力需要通过新契约版本演进。
