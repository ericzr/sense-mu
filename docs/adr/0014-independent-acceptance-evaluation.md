# ADR-0014：生产发布只信任独立验收评测

- 状态：Accepted
- 日期：2026-08-09

## 决策

训练过程产生的验证指标只作为早期质量信号，不再直接授予生产发布资格。生产部署必须引用一条来源为 `acceptance-dataset`、通过当前门禁策略的评测记录。

验收任务使用现有 `Run`、执行租约和追加式事件链，其任务类型为 `model.acceptance-evaluate`。平台不为评测再建一套调度和重试系统。

## 数据独立性

验收数据必须是同一项目下的冻结 `DatasetVersion`，不能与候选模型的训练版本相同，并且类别编号和名称必须完全一致。现有冻结契约继续要求训练集与验证集都存在，不为验收场景引入第二种数据版本类型。

Worker 优先使用验收版本的测试集，没有测试集时才使用验证集。当前的“独立”由不同的不可变版本标识保证，尚不提供跨版本图像内容相似度检测。

## 执行与报告

任务规格在提交时固定模型产物、数据 manifest、门禁版本、图像尺寸、批量和 Ultralytics 运行镜像。Worker 先将模型与数据物化到本地，再在断网 Docker 容器内执行真实验收推理，不下载未固定的外部资源。

完成时 API 用 Worker 回传的真实指标逐条执行固定门禁，并将运行镜像、资产数、指标、阈值、实际值和结论写入不可变 `report.json`。评测完成期间如果门禁已被新版本取代，历史报告仍保留，但不会成为当前发布资格。

## 非目标

本次不建设隐藏榜单、跨项目公共基准、模型统计显著性比较、数据泄漏相似度扫描或多模型并行赛马。这些能力只在明确的验收治理需求出现后再引入。
